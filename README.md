# くらしの手帳

支払い・履修・時間割・予定・バイト・相談をひとつにまとめた、自分用のアプリです。
GitHub Pages（https://yurizigong95.github.io/kurashi/ ）で動かします。

## ファイルの中身

| 場所 | 中身 |
|---|---|
| `index.html` | 画面の骨組み（ここから下のファイルを読みこむ） |
| `css/app.css` | 見た目 |
| `js/data.js` | 科目・時刻表・履修のデータ |
| `js/core.js` | 共通の道具・保存・取り消す・エラーの記録 |
| `js/sync.js` | 端末どうしの同期（写真もふくむ） |
| `js/ai.js` | AI（Gemini）を呼ぶ道具 |
| `js/google.js` | Googleカレンダー・Googleドライブとの連携 |
| `js/*.js`（そのほか） | 各画面（今日・時間割・予定・お金・そうだん など） |
| `gas/Code.gs` | Google連携の「橋わたし」（Apps Script に貼るプログラム） |
| `tests/` | 自動テスト（本物のデータには触れません） |
| `sw.js` / `manifest.json` / `icon-*.png` | ホーム画面に置いたときのための設定 |

`js/` のファイルは、`index.html` に書いた順番で読みこみます。順番は変えないでください。

## GitHub に上げるとき

1. GitHub の `kurashi` リポジトリを開く
2. 「Add file」→「Upload files」
3. **このフォルダの中身をまるごと**（`css` `js` `gas` `tests` フォルダもいっしょに）ドラッグして「Commit changes」
4. 数分後、スマホ・iPad・パソコンでアプリを開き直す
5. 設定 › 端末どうしの同期 で、どの端末も同じ版（`APP_BUILD`）になっているか確かめる

## テストのしかた

パソコンで `tests/index.html` を開くと、2台の端末をまねて自動でたしかめます
（`https://yurizigong95.github.io/kurashi/tests/` でも動きます）。
テストは「テストモード」で動くので、本物のデータ・Firebase・Googleには触れません。
アプリ本体も、URLに `?test=1` をつけるとテストモードになります。

## Google連携（カレンダー・ドライブ）のつなぎ方

アプリの 設定 › Google連携 に、同じ手順が出ます。

1. 「合言葉を作って、プログラムをコピー」を押す
2. https://script.google.com で「新しいプロジェクト」→ 中身をぜんぶ消して貼り付け → 保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ Googleの確認で許可（「このアプリは確認されていません」→「詳細」→「移動」）
5. 出てきた「ウェブアプリのURL」をアプリに貼って「保存して、つながるか試す」

- 予定は Googleカレンダーの「くらしの手帳」というカレンダーに入ります。通知は **前日の0時** です。
- バックアップは Googleドライブの「くらしの手帳バックアップ」フォルダに、週に1回（新しい12回分）入ります。
- 合言葉とURLは端末ごとに保存されます（同期はしません）。1台だけつないでおけば、ほかの端末の変更もその端末から送られます。
- プログラムを直したときは、「デプロイを管理」→ 編集 → 新しいバージョン で入れ直してください。

## Firebase のルール（念のため確認）

Firebase コンソール › Firestore Database › ルール が「テストモード（期限つき）」のままだと、
期限が来た日から同期が止まります。次のようにしておくと、期限なしで、このアプリの文書だけを使えます。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shiharai/{doc} {
      allow read, write: if doc.matches('8b7f4e6et9jhxded.*');
    }
  }
}
```

※ このやり方では、部屋のID（上の英数字）を知っている人は読み書きできます。
部屋のIDはアプリのファイルの中に書いてあるので、より安全にするには、同期するデータの暗号化かログインのしくみが必要です。
