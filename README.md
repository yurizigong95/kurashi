# くらしの手帳

支払い・履修・時間割・予定・バイト・相談をひとつにまとめた、自分用のアプリです。
GitHub Pages（https://yurizigong95.github.io/kurashi/ ）で動かします。

## 公開のしかた（GitHub に上げる）

このフォルダは GitHub の `kurashi` リポジトリとつながっています。

- **`tools/公開.bat` をダブルクリック**するだけで、ファイルの確認 → GitHub へのアップロードまで自動でします
  （Claude に「公開して」と頼んでも同じです）
- 1〜3分で https://yurizigong95.github.io/kurashi/ に反映されます。スマホ・iPad・パソコンでアプリを開き直してください
- 設定 › 端末どうしの同期 で、どの端末も同じ版（`APP_BUILD`）になっているか確かめられます
- はじめての時だけ、ブラウザで GitHub のログインが出ます（そのあとは覚えています）
- アップロードのたびに、GitHubの「Actions」タブで自動テスト・ファイルの抜け・表示の速さ（Lighthouse）が動きます

GitHub のページから「Upload files」で上げるのは、なるべくやめてください（パソコンの中身とずれて、`公開.bat` が失敗します）。

アプリのファイルが足りないときは、アプリが「アプリを開けませんでした」と原因を出します。
古いファイルが残っているときは、その画面の「しまってある古いファイルを消して読みこむ」を押してください（予定などのデータは消えません）。

## テストのしかた

パソコンで `tests/index.html` を開くと、2台の端末をまねて自動でたしかめます
（`https://yurizigong95.github.io/kurashi/tests/` でも動きます）。
テストは「テストモード」で動くので、本物のデータ・Firebase・Googleには触れません。
アプリ本体も、URLに `?test=1` をつけるとテストモードになります。

## Google連携（カレンダー・ドライブ・ToDo・通知・ショートカット）のつなぎ方

アプリの 設定 › Google連携 に、同じ手順が出ます。

1. 「合言葉を作って、プログラムをコピー」を押す
2. https://script.google.com で「新しいプロジェクト」→ Code.gs の中身をぜんぶ消して貼り付け → 保存
3. 左の「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` を「設定ファイルをコピー」の中身に置きかえて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ Googleの確認で許可（「このアプリは確認されていません」→「詳細」→「移動」）
6. 出てきた「ウェブアプリのURL」をアプリに貼って「保存して、つながるか試す」（5分ごとの確認も自動で動きます）

### スマホへの通知

1. Firebase コンソール › プロジェクトの設定 › Cloud Messaging › ウェブプッシュ証明書 で「鍵ペアを生成」
2. その鍵をアプリの 設定 › 通知 に貼って保存
3. iPhoneは **ホーム画面に追加したアプリ** から「この端末で通知を受け取る」（iOS 16.4以降）
4. テストが届かないときは、Firebase の「サービスアカウント」で作った秘密鍵（JSON）の中身を、Apps Script の「プロジェクトの設定 › スクリプト プロパティ」に `SA_JSON` という名前で入れると、そちらの権限で送ります

- 予定は Googleカレンダーの「くらしの手帳」というカレンダーに入ります。通知は **前日の0時** です。
- バックアップは Googleドライブの「くらしの手帳バックアップ」フォルダに、週に1回（新しい12回分）入ります。
- 合言葉とURLは端末ごとに保存されます（同期はしません）。1台だけつないでおけば、ほかの端末の変更もその端末から送られます。
- プログラムを直したときは、「デプロイを管理」→ 編集 → 新しいバージョン で入れ直してください。

## Firebase のルール（念のため確認）

Firebase コンソール › Firestore Database › ルール が「テストモード（期限つき）」のままだと、
期限が来た日から同期が止まります。次のようにしておくと、期限なしで、このアプリの文書だけを使えます。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shiharai/{doc} {
      allow read, write: if doc.matches('8b7f4e6et9jhxded.*');
    }
  }
}
```

※ このやり方では、部屋のID（上の英数字）を知っている人は読み書きできます。
部屋のIDはアプリのファイルの中に書いてあるので、より安全にするには、同期するデータの暗号化かログインのしくみが必要です。
