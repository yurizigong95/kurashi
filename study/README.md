# もんだいメーカー

授業の写真・スライド・配布資料から、**自分だけの問題集**を作って解く勉強アプリです。
看護学部の1年生が使うことを考えて作っています。

- 公開先： https://yurizigong95.github.io/kurashi/study/
- 「くらしの手帳」とは**別のアプリ**です。保存場所も別なので、どちらかを消しても、もう一方は消えません。
- **スマホ・iPad・パソコンで、ひとりでにそろいます**（科目・資料・問題・といた記録・にが手ノート・資料の写真）。くらしの手帳と同じつなぎ先を使うので、その端末で手帳をいちど開いていれば、設定はいりません。APIキーと使った量の記録だけは、端末ごとのままです。
- 3つのアプリ（くらしの手帳・もんだいメーカー・ゲーム道場）をまとめて使える「ぜんぶ入り」（ https://yurizigong95.github.io/kurashi/all/ ）からも開けます。中身はこのアプリそのままで、保存したものも同じです。
- ふつうのウェブページなので、iPhoneのSafariで開いて「ホーム画面に追加」すると、アプリのように使えます。
  一度ひらけば、電波がなくても（オフラインでも）解けます。

## 6つのタブ

| タブ | できること |
|---|---|
| 🏠 ホーム | きょうの目標と進みぐあい・つづけた日数・科目ごとの残り |
| ✍️ とく | 復習／はじめて／まちがい直し／★／ぜんぶ。模擬テスト・にが手ノートもここ |
| 📝 メモ | 授業中に書いて、あとでさがす。科目・第◯回・★で整理。「この文から問題をつくる」で、そのまま問題にできます |
| 📸 つくる | 資料から問題を作る（AIあり）／組みこみの表から作る（AIなし）。写真・PDF・スライド・Word・文章・ZIP・**講義の録音や動画**（大きくても大丈夫。2GBまで） |
| 🗂 科目 | 科目の追加・名前の変更・並べ替え・色・学期・国試の分野。資料と問題の整理 |
| ⚙️ 設定 | APIキー・1日の目標・成績・バックアップ |

## 問題の作り方は2とおり

### 1. 資料から作る（AIを使う）
写真・PDF・PowerPoint（.pptx）・Word（.docx）・テキスト・ZIP・**講義の録音（.m4a/.mp3/.wav）や動画（.mp4/.mov）**・貼りつけた文章から作ります。
スライドやWordは、**中の字だけ**を取り出して送るので、写真を送るより通信もAPIも軽くなります。

**大きなファイルでも大丈夫です（2GBまで）。**

| 種類 | 大きいときのやり方 |
|---|---|
| スライド・Word・ZIP | 中の**必要なところだけ**を読みます。400MBのスライドでも、開くのは一瞬で、端末のメモリはほとんど使いません |
| PDF・録音・動画 | 15MBより大きいものは、Geminiに**少しずつ（8MBずつ）預けてから**読んでもらいます。送っているあいだ、進みぐあい（％）が出ます |
| 文章 | 長いものは、はじめの4MBぶんだけ読みます（問題を作るには十分です） |

預けたファイルは、Google側で48時間ほどで自動的に消えます。APIキーはこの端末の中だけに保存します。

作るときにえらべること：問題の数／種類（4択・○×・穴うめ・記述・並べかえ・組み合わせ）／
むずかしさ（基本・ふつう・応用・2通り）／事例・定期テストふう・国試ふう・英語・「2つ選べ」。

### 2. 組みこみの表から作る（AIを使わない・APIゼロ）
アプリの中に、たしかめた表が入っています。ここからは**通信もAIもなし**で問題が作れます。

| もと | 数 | 作れる問題 |
|---|---|---|
| 検査の基準値 | 149 | 4択・穴うめ |
| 略語・用語 | 334 | 意味・英語の正式名・組み合わせ |
| 薬 | 95 | はたらき・副作用 |
| 看護技術の手順 | 21 | 並べかえ・根拠（なぜそうするか） |
| 解剖の図 | 4 | 図の「？」あて |
| 国試ふうの練習問題 | 72 | 分野べつ |
| 看護の計算 | 12種 | 点滴の滴下数・流量・輸液時間・体重あたりの薬・w/v％・うすめる・酸素ボンベ・BMI・標準体重・尿量・錠数（数字は毎回かわり、式も出ます） |

資料の字からも、AIなしで穴うめ・○×を作れます（「つくる」→「AIなし」）。

## APIの使用量をへらす工夫

- 字が取り出せた資料は、写真を送らない
- 前に作った問題の問題文を**28字だけ**送って、かぶりを防ぐ
- やさしい版・むずかしい版を**1回**でまとめて作る
- まちがいの「なぜ？」は、まず手もとの表でしらべ、見つからないときだけAI。答えは覚えて2回目は呼ばない
- 作るのを途中でやめられる／通信が切れたら「もう一度ためす」／1問だけ作り直す
- 設定タブに「AIを呼んだ回数」と「AIなしで作った問題の数」が出ます

## はじめかた

1. 「科目」タブで、授業の名前を足す（よくある科目はボタンで足せます）
2. 「つくる」タブで、授業の資料をえらぶ → できた問題をたしかめて入れる
3. 「とく」タブで解く。正解がつづくほど、次に出るまでの日がのびます（1→3→7→14→30→60日）

AIを使うときは、設定タブに Gemini の APIキーを入れてください。
キーは Google AI Studio（aistudio.google.com）の「Get API key」で作れます。
**キーはこの端末の中だけに保存します**（どこにも送りません）。キーがなくても、表から作る問題と、解く機能はぜんぶ使えます。

## 気をつけること

- AIが作った問題は、かならず**教科書・先生の資料で確かめて**ください（出典と注意書きを必ず出します）
- 実習記録など、**患者さんの情報が書いてある資料は読みこまないで**ください（AIに送られます）
- 基準値や手順は、教科書・施設によって少しちがいます。**学校で習ったものを優先**してください

## ファイルの中身

| 場所 | 中身 |
|---|---|
| `index.html` | 画面の骨組み（ここから下のファイルを読みこむ） |
| `css/app.css` | 見た目（夜モードつき） |
| `js/core.js` | 小道具・保存・写真（IndexedDB）・画面の描き直し |
| `js/data.js` | 先に入れてある表（基準値・略語・薬・手順・解剖図・練習問題・計算・分野・単元・取りちがえ語） |
| `js/ai.js` | Gemini を呼ぶ道具（キーはこの端末の中だけ） |
| `js/model.js` | 科目・資料・問題・記録の形と、答え合わせ |
| `js/ui.js` | 画面のかけら（カード・チップ・ボタン） |
| `js/files.js` | 資料の読みこみ（zip・OOXML・EXIF・写真の手入れ） |
| `js/gen.js` | AIを使わない問題づくり |
| `js/make.js` / `js/make-view.js` | 「つくる」タブ |
| `js/drill.js` | 「とく」タブ（出題・採点・模擬テスト・にが手ノート） |
| `js/lib.js` | 「科目」タブ（科目・資料・問題の整理） |
| `js/home.js` / `js/set.js` | 「ホーム」「設定」タブ |
| `js/main.js` | はじまり |
| `sw.js` / `manifest.json` | オフラインで使う・ホーム画面に追加する |
| `tests/` | 自動テスト（ブラウザで `tests/index.html` を開くと走ります） |
| `docs/ふやせる機能200.md` | これから足せる機能の案（✅ が入っているもの） |

## テスト

`tests/index.html` をブラウザで開くと、アプリを本物と同じように動かして確かめます（AIはにせものに差しかわります）。
`?only=ことば` を付けると、名前に合うテストだけ走ります。
