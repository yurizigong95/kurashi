# かんご実習メーカー

学習用の**架空の事例（ペーパーペイシェント）**で、看護過程を練習するアプリです。

- 公開先： https://yurizigong95.github.io/kurashi/care/
- **これは学習用の架空事例アプリです。実在の患者さんの情報は入力しないでください。**（画面の上に、いつも出ています）
- 「くらしの手帳」「もんだいメーカー」とは**別のアプリ**です。保存場所も別です。
- スマホ・iPad・パソコンのどれで開いても、ひとりでにそろいます（事例・看護過程・AI壁打ちの記録・AIのかしこさの設定）。
  つなぎ先はくらしの手帳と同じ Firebase・同じ合言葉で、置き場所の名前は `合言葉__care_…`（`idx`・`p0`…・`devs`）です。
  APIキーと使った量の記録は同期しません。
- 「ぜんぶ入り」（ https://yurizigong95.github.io/kurashi/all/ ）の「かんご」からも開けます。

## 4つのタブ

| タブ | できること |
|---|---|
| 📚 事例 | 事例ライブラリ。事例名・年齢層・性別・疾患名（架空）・状況メモの登録・編集・一覧。はじめに学習用の事例が3つ入っています（高齢者の肺炎・糖尿病の教育入院・大腿骨骨折の術後） |
| 🩺 看護過程 | 事例ごとのワークスペース：情報整理（見出しつきメモ）・アセスメント（ブロックを足せる）・看護問題リスト（優先度 高/中/低）・看護計画（問題ごとに O-P/T-P/E-P）・実施・評価メモ（日付つき） |
| 💬 AI壁打ち | 事例の中身をAI（Gemini）にわたして相談する。看護問題の候補出し・看護計画のレビューなど |
| ⚙️ 設定 | APIキー・AIのかしこさ・使った量・同期・バックアップ |

## AIのキー

もんだいメーカーと同じく、くらしの手帳（設定 › AIそうだん）に入れた Gemini のキーを、同じ端末の中で**そのまま自動で**使います。
このアプリの設定で別のキーを入れることもできます（この端末の中だけに保存し、同期しません）。
使うモデルは、くらしの手帳と同じ順（gemini-3.6-flash → gemini-2.5-flash → gemini-flash-latest → gemini-2.0-flash）でためします。

## ファイルの中身

| 場所 | 中身 |
|---|---|
| `index.html` | 画面の骨組み（ここから下のファイルを読みこむ） |
| `css/app.css` | 見た目（夜モードつき） |
| `js/core.js` | 小道具・保存・画面の描き直し・版（`APP_BUILD`） |
| `js/data.js` | 学習用の事例・見出しのひな形・AIへのよく使う相談 |
| `js/ai.js` | Gemini を呼ぶ道具（`aiCall`） |
| `js/model.js` | 事例と看護過程の形 |
| `js/sync.js` | ほかの端末とそろえる（もんだいメーカーと同じしくみ） |
| `js/ui.js` | 画面のかけら |
| `js/cases.js` / `js/work.js` / `js/chat.js` / `js/set.js` | 「事例」「看護過程」「AI壁打ち」「設定」タブ |
| `js/main.js` | はじまり |
| `sw.js` / `manifest.json` | オフラインで使う・ホーム画面に追加する（新しい版を出すときは `sw.js` の `CACHE` も上げる） |
