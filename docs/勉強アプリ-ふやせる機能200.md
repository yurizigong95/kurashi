# 授業の資料から問題を作るアプリ：ふやせる機能 200

看護学部1年生の使いかたを考えて出した、200個のアイデアです。
**✅ が付いているものは、この版（2026-09-22a）でもう使えます。** ほかは、これから足せる案です。

各行のおわりの印
- `かんたん` … 1つの画面の中だけで作れる（半日くらい）
- `ふつう` … データの形を少し足す（1〜2日くらい）
- `大きい` … 新しい画面やしくみがいる（数日〜）
